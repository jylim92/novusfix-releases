# NovusFix Releases

Official release repository for **NovusFix Professional**.

NovusFix Professional is a Windows PC diagnostic and repair utility focused on system health checks, repair guidance, cleanup, crash forensics, and performance troubleshooting.

## What this repository is for

This repository is used to publish official **NovusFix Professional** release files and release notes.

- **Download builds:** in the [Releases](../../releases) section
- **Billing and subscriptions:** handled through **Lemon Squeezy**
- **Authenticity:** official executables are **code-signed**

Please download NovusFix only from this repository or official NovusFix links.

## Download

Get the latest build from the [Releases](../../releases) page.

Each release may include:
- Windows ZIP package
- version number
- release notes
- upgrade notes or known issues

## How to use

1. Open the [Releases](../../releases) page.
2. Download the latest ZIP file.
3. Extract the ZIP.
4. Run `NovusFixPro.exe`.

## Subscription and activation

NovusFix Professional is distributed commercially through **Lemon Squeezy**.

Depending on your plan and app version, access to Pro features may require:

## System requirements

- Windows 10 or Windows 11
- 64-bit system
- Internet connection may be required for sign-in, subscription verification, updates, or some features

## Security and authenticity

Official NovusFix builds are **code-signed**.

Before running the app:
- make sure the file was downloaded from this official repository or an official NovusFix link
- verify the publisher shown by Windows matches your official signing identity
- avoid third-party download sites
